# Toyless

[![Status](https://img.shields.io/badge/Status-Work_in_Progress-orange.svg)](Status)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-RP2040_%7C_Pico_W-lightgrey.svg)](Platform)

**Toyless** - открытый аппаратный эмулятор базы *Disney Infinity* для Xbox 360 на базе микроконтроллера Raspberry Pi Pico W. Проект решает проблему недоступности и дороговизны оригинальной физической базы и фигурок, позволяя играть и управлять фигурками через встроенный веб-интерфейс без использования настоящих NFC-игрушек.

> [!WARNING]
> **Проект находится в стадии активной разработки**
> Базовый низкоуровневый стэк (USB-дескрипторы, межъядерная коммуникация, и аутентификация через XSM3) уже реализован и протестирован на железе. Логика игрового протокола и веб-интерфейс находятся в разработке либо интеграции

## Архитектура

Проект использует двухъядерный асиметричную архитектуру RP2040:
- **Core 0**: обслуживает USB-стэк, обработку прерываний и криптографические вычисления аутентификации
- **Core 1**: обслуживает Wi-Fi стэк и HTTP веб-сервер

## Основные возможности

### Уже реализовано

- Аутентификация по XSM3 на основе libxsm3
- Точная калибровка дескрипторов устройства на основе реальной базы Disney Infinity от PDP (VID 0x24C6, PID 0xFA00, 4 интерфейса XInput)
- Изоляция ядер, чтобы сетевой и файловый функционал не прерывали обработку USB-трафика.
- Неблокирующее кольцевое логирование в UART

### В разработке

- Движок протокола Disney Infinity, генерация фигурок
- Веб-интерфейс для управления виртуальной базой
- Запись созданных фигурок во внутреннюю память 

## Установка и сборка

На текущий момент проект находится в активной разработке, следовательно готовых релизов пока нет. 

### Требования к окружению

Для кросс-компиляции под RP2040 требуются:
- arm-none-eabi-gcc (версия 12+) и newlib
- cmake (версия 3.20+)
- ninja или make
- git

### Сборка прошивки

1. Клонируйте репозиторий вместе с необходимыми сабмодулями (Pico SDK):

```bash
git clone --recurse-submodules https://github.com/ChargeChallenger/toyless.git
cd toyless
```

2. Сконфигурируйте проект при помощи CMake:

```bash
cmake -B build -G Ninja
```

3. Запустите сборку:

```bash
ninja -C build
```

После сборки в папке `build` должен появится `toyless.uf2`

## Использование и прошивка

### Прошивка микроконтроллера
1. Зажмите кнопку BOOTSEL на плате Raspberry Pi Pico W и подключите её к ПК кабелем Micro-USB.
2. Плата определится как съемный накопитель RPI-RP2.
3. Скопируйте файл build/toyless.uf2 в корень накопителя. Плата автоматически перезагрузится и запустит прошивку.
### Отладка по UART (опционально)
Для наблюдения за логами в реальном времени подключите любой USB-UART переходник к выводам платы:
- GP0 (TX) Pico W -> RX переходника
- GP1 (RX) Pico W -> TX переходника
- GND Pico W -> GND переходника

Параметры терминала: `115200 baud, 8N1`:
```
minicom -D /dev/ttyACM0 -b 115200
```

### Использованные библиотеки

* **[Raspberry Pi Pico SDK](https://github.com/raspberrypi/pico-sdk)** (BSD 3-Clause) - официальный SDK для RP2040, включая встроенный USB-стек
[TinyUSB](https://github.com/hathach/tinyusb) (MIT).
* **[littlefs](https://github.com/littlefs-project/littlefs)** (BSD 3-Clause) - файловая система для flash-памяти микроконтроллеров (хранение дампов и сохранений).
* **[libxsm3](https://github.com/InvoxiPlayGames/libxsm3)** (LGPL-2.1+) от **InvoxiPlayGames**:
    * Включает криптографические примитивы [ExCrypt](https://github.com/emoose/ExCrypt) от **emoose** (BSD 3-Clause).
    * Базируется на исследованиях архитектуры XSM3 от **[oct0xor](https://github.com/oct0xor)** и **[sanjay900](https://github.com/sanjay900)**.
